## Core capabilities

**Mechanical design**  
SolidWorks, advanced drawings, sheet metal, weldments, CATIA V5, AutoCAD, GD&T, tolerance analysis, DFM and DFA.

**Precision metrology**  
Uncertainty-driven design, calibration strategy, gauge R&R, Cp and Cpk, SPC control charts, traceability, test protocols, and acceptance criteria.

**Technical project delivery**  
Requirements, milestone planning, design reviews, risk mitigation, supplier coordination, configuration and BOM management, verification, commissioning, and production handover.

**Automation and analysis**  
Python, MATLAB, VBA, SolidWorks Simulation, robotic calibration, computer vision, and structured experimental validation.
